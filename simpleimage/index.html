What's new

USB drives: plug in a USB drive and choose photos and PDFs from it, or save pictures onto it. In the file picker, All folders is now right next to Recent.

How to install or update

  1. Tap Download above. If the browser warns about the file, tap Download anyway.
  2. When it finishes, tap Open (or open the file from your Downloads).
  3. The first time, the phone asks to allow installing from your browser: switch it on and go back.
  4. If Google Play Protect asks, tap Scan app, then Install or Update.

Updating keeps your Recent work. After this, the app tells you itself when a new version is ready.
